# スプリント契約

## 対象範囲

機能: アプリ起動・基本アプリシェル

対象要件: FR-001

## 観測可能な振る舞い

- macOSでアプリを起動できる。
- Windowsでアプリを起動できる。
- アプリ名としてMuziaが表示される。
- サイドバー、ツールバー、メインコンテンツ領域、プレイヤー領域を含む基本レイアウトが表示される。
- 起動時に読み込み中状態が表示される。
- ライブラリが存在しない場合に空状態が表示される。
- 初期化または読み込みに失敗した場合にエラー状態が表示される。
- 未実装の機能が実装済みであるかのように表示されない。
- ウィンドウサイズを変更しても主要な領域が極端に崩れない。

## 安全性とアーキテクチャ上の制約

- `docs/architecture.md`のレイヤー分離に従う。
- 起動状態をWidgetに直接実装せず、ViewModelまたは同等の状態管理層で管理する。
- 本スプリントではユーザーの音楽ファイルへアクセス、変更、削除を行わない。
- 対象外に定義された音楽フォルダ登録、再生、検索などを実装済みとして扱わない。

## Evaluatorが提示すべき証拠

- macOSでアプリを起動した結果。
- Windowsでアプリを起動した結果。
- loading、empty、error各状態を表示した結果。
- 基本レイアウトとウィンドウサイズ変更後の表示確認。
- 起動状態を検証するWidget Testの結果。
- `flutter analyze`と`flutter test`の結果。

## Evaluatorの判定

すべての観測可能な振る舞いが確認できた場合だけ`PASS`とする。
いずれかの振る舞いが不足、誤動作、または検証不能の場合は`FAIL`とする。

## Evaluatorのフィードバック

不合格の場合は、以下を記録する。

- 不合格となった振る舞い。
- 再現手順。
- 観測した結果と期待される結果。
- Generatorが次に行う最小限の修正。
