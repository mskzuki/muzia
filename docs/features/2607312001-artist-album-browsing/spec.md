# アーティスト・アルバム閲覧 仕様書

## 文書情報

- 仕様ID: 2607312002
- 対応する全体要件: FR-006、FR-007
- ステータス: Completed
- 作成日: 2026-07-31

## 1. 目的

ライブラリの楽曲メタデータからアーティストとアルバムを整理して表示し、目的の楽曲へ辿れるようにする。

## 2. 対象範囲

### 対象

- アクティブな楽曲からのアーティスト一覧生成
- 選択したアーティストに紐づくアルバム一覧表示
- アルバム選択後の楽曲一覧表示
- 空状態、エラー状態、選択状態の表示

### 対象外

- アーティスト名・アルバム名の正規化
- アルバムアート
- プレイリスト、お気に入り、タグ

## 3. 要件

### 機能要件

- [x] REQ-001: 楽曲が存在するアーティストだけを一覧表示する。
- [x] REQ-002: アーティストを選択できる。
- [x] REQ-003: 選択したアーティストのアルバムだけを表示する。
- [x] REQ-004: アルバムを選択すると所属楽曲を表示する。
- [x] REQ-005: 空欄のアーティスト・アルバムを一覧名として表示しない。
- [x] REQ-006: ライブラリから削除済みの楽曲を集計対象から除外する。

### 非機能要件

- [x] NFR-001: グルーピングとソートをDomain/Repositoryでテスト可能にする。
- [x] NFR-002: 大量の楽曲でも一覧操作を継続できる。

## 4. 完了条件

- [x] アーティスト、アルバム、楽曲の3段階を閲覧できる。
- [x] 空状態とエラー状態を表示できる。
- [x] グルーピング・除外ロジックの単体テストとWidgetテストが成功する。
- [x] `flutter analyze` と `flutter test` が成功する。

## 5. 設計メモ

アーティストとアルバムは独立マスターテーブルにせず、`track_metadata`から生成する。削除済み判定は`tracks.removed_at IS NULL`を正とする。
