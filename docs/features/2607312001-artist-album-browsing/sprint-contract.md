# スプリント契約

## 対象範囲

機能: アーティスト・アルバム閲覧

対象要件: FR-006、FR-007

## デザインハンドオフ比較

- `docs/design_handoff/` のアーティスト・アルバム関連資料と実装を比較する。
- 一覧、選択状態、空状態、楽曲表示の構成・余白・色・タイポグラフィを確認し、差異があれば理由と受け入れ可否を証拠に記録する。

## 観測可能な振る舞い

- 楽曲が存在するアーティストだけが一覧に表示される。
- アーティストを選択すると、対応するアルバムだけが表示される。
- アルバムを選択すると、所属する楽曲が表示される。
- 空欄のアーティスト・アルバムや削除済み楽曲が一覧に混入しない。

## 証拠

- アーティスト、アルバム、楽曲のWidget Test結果。
- グルーピングと除外ロジックの単体Test結果。
- macOS / Windowsでの閲覧フローのIntegration Test結果。

## 判定

すべての振る舞いとテスト結果を確認できた場合のみPASSとする。未確認または誤動作がある場合はFAILとし、再現手順と最小修正項目を記録する。
