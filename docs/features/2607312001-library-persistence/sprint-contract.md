# スプリント契約

## 対象範囲

機能: ライブラリ永続化

対象要件: FR-010

## デザインハンドオフ比較

- `docs/design_handoff/` のloading、empty、success、error状態に関する資料と実装を比較する。
- 状態表示の構成、メッセージ、余白、色、タイポグラフィを確認し、差異があれば理由と受け入れ可否を証拠に記録する。

## 観測可能な振る舞い

- アプリ再起動後も登録フォルダが保持される。
- 検出済み楽曲とアプリ上のメタデータが保持される。
- 編集済みメタデータとライブラリからの削除状態が保持される。
- 起動時にloading、成功、empty、errorの状態が表示される。
- DBエラーがユーザーに確認可能なエラーとして表示される。

## 証拠

- インメモリDBによるRepository・トランザクションTest結果。
- 起動状態とエラー状態のWidget Test結果。
- macOS / Windowsでの再起動Integration Test結果。

## 判定

保存対象を再起動前後で比較し、すべて保持されることを確認できた場合のみPASSとする。
