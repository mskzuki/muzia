# スプリント契約

## 対象範囲

機能: ライブラリからの楽曲削除

対象要件: FR-013、FR-014

## 観測可能な振る舞い

- 削除前に対象楽曲と件数、元ファイルを削除しないことが表示される。
- 確認後、対象楽曲がライブラリから除外される。
- 一覧、検索、アーティスト、アルバムから削除済み楽曲が除外される。
- 元の音楽ファイルが残る。
- 保存失敗時にエラーが表示され、状態が不整合にならない。

## 証拠

- 単一・複数削除と失敗処理の単体Test結果。
- 確認ダイアログのWidget Test結果。
- 元ファイル非削除と再起動後の状態保持を確認するIntegration Test結果。

## 判定

確認、論理削除、ファイル安全性、再起動後の保持をすべて確認できた場合のみPASSとする。
