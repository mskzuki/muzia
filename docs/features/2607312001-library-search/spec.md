# ライブラリ検索 仕様書

## 文書情報

- 仕様ID: 2607312003

- ステータス: Completed
- 作成日: 2026-07-31

## 1. 目的

タイトル、アーティスト、アルバムを横断して検索し、楽曲数が増えても目的の楽曲を素早く見つけられるようにする。

## 2. 対象範囲

### 対象

- 検索語の入力・クリア
- タイトル、アーティスト、アルバムへの部分一致検索
- 大文字・小文字を区別しない検索
- 検索結果、0件、入力待ち、エラー状態の表示

### 対象外

- 全文検索エンジンやSQLite FTS
- 高度な検索構文、検索履歴、スマートプレイリスト

## 3. 要件

### 機能要件

- [x] REQ-001: 検索語でタイトル、アーティスト、アルバムを検索できる。
- [x] REQ-002: 3項目のいずれかに一致する楽曲を表示する。
- [x] REQ-003: 大文字・小文字の違いにかかわらず検索できる。
- [x] REQ-004: 検索語をクリアして通常の一覧へ戻れる。
- [x] REQ-005: 結果がない場合は明示的な空状態を表示する。
- [x] REQ-006: 削除済み楽曲を検索結果へ含めない。

### 非機能要件

- [x] NFR-001: 検索ロジックをWidgetから分離し単体テストできる。
- [x] NFR-002: 検索中にUIをブロックしない。

## 4. 完了条件

- [x] タイトル、アーティスト、アルバムそれぞれの検索が動作する。
- [x] 0件、クリア、エラー状態を確認できる。
- [x] 単体、Widget、主要Integration Testが成功する。
- [x] `flutter analyze` と `flutter test` が成功する。

## 5. 設計メモ

初期実装は`docs/database.md`に従い通常のLIKE相当の検索とする。性能上の問題が確認されるまではFTSを導入しない。
