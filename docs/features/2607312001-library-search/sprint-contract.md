# スプリント契約

## 対象範囲

機能: ライブラリ検索

対象要件: FR-008

## デザインハンドオフ比較

- `docs/design_handoff/` の検索入力、検索結果、検索結果なし、エラー状態に関する資料と実装を比較する。
- 入力欄、一覧、状態表示の構成・余白・色・タイポグラフィを確認し、差異があれば理由と受け入れ可否を証拠に記録する。

## 観測可能な振る舞い

- タイトル、アーティスト、アルバムのいずれでも部分一致検索できる。
- 大文字・小文字の違いにかかわらず検索できる。
- 検索結果が0件の場合、その状態が表示される。
- 検索語をクリアすると通常の楽曲一覧へ戻る。
- 削除済み楽曲は検索結果に表示されない。

## 証拠

- 検索ロジックの単体Test結果。
- 検索入力、結果表示、クリアのWidget Test結果。
- macOS / Windowsでの検索Integration Test結果。

## 判定

全検索対象と空結果・クリアの振る舞いを確認できた場合のみPASSとする。
