# メタデータ編集・一括編集 仕様書

## 文書情報

- 仕様ID: 2607312006
- 対応する全体要件: FR-011、FR-012、FR-014
- ステータス: Draft
- 作成日: 2026-07-31

## 1. 目的

ユーザーがアプリ内で楽曲情報を修正し、複数楽曲へ同じ変更を安全に適用できるようにする。

## 2. 対象範囲

### 対象

- タイトル、アーティスト、アルバム、リリース情報の個別編集
- 複数楽曲の選択・選択解除と選択数表示
- 対象項目を指定した一括編集
- 保存、キャンセル、入力検証、失敗結果の表示
- 一覧、検索、アーティスト、アルバムへの変更反映

### 対象外

- 音楽ファイルへの書き戻し
- アルバムアート編集
- 編集履歴、元に戻す機能

## 3. 要件

### 機能要件

- [ ] REQ-001: 現在の値を確認して編集画面を開ける。
- [ ] REQ-002: 4項目を個別に変更、保存、キャンセルできる。
- [ ] REQ-003: 複数楽曲を選択・選択解除でき、選択数を表示する。
- [ ] REQ-004: 一括変更の項目と値を確認して保存できる。
- [ ] REQ-005: 保存後、全対象画面へ変更を反映する。
- [ ] REQ-006: 保存失敗時に結果とエラーを表示し、可能な限りロールバックする。
- [ ] REQ-007: 元の音楽ファイルの内容・メタデータを変更しない。

### 非機能要件

- [ ] NFR-001: 一括編集を1トランザクションで実行する。
- [ ] NFR-002: 入力検証と更新ロジックをViewModel/Repositoryでテスト可能にする。

## 4. 完了条件

- [ ] 個別編集と一括編集が動作する。
- [ ] キャンセル、失敗、ロールバックを確認できる。
- [ ] 元ファイルが変更されないことをテストで確認する。
- [ ] `flutter analyze` と `flutter test`、必要なIntegration Testが成功する。

## 5. 設計メモ

表示・検索の正は`track_metadata`とする。元ファイル由来の値は`track_source_metadata`に保持し、編集では変更しない。更新は`MetadataRepository`のトランザクションで行う。
