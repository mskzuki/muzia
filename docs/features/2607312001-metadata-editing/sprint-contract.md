# スプリント契約

## 対象範囲

機能: メタデータ編集・一括編集

対象要件: FR-011、FR-012、FR-014

## デザインハンドオフ比較

- `docs/design_handoff/` の編集フォーム、一括編集、確認、保存中、成功、エラー状態に関する資料と実装を比較する。
- 入力欄、ダイアログ、確認操作、状態表示の構成・余白・色・タイポグラフィを確認し、差異があれば理由と受け入れ可否を証拠に記録する。

## 観測可能な振る舞い

- タイトル、アーティスト、アルバム、リリース情報を個別に編集・保存・キャンセルできる。
- 複数楽曲を選択・解除でき、選択数が表示される。
- 指定したメタデータを選択楽曲へ一括反映できる。
- 保存後、一覧、検索、アーティスト、アルバムの表示へ反映される。
- 保存失敗時にエラーが表示され、可能な限り変更がロールバックされる。
- 元の音楽ファイルが変更されない。

## 証拠

- 個別編集・一括編集・ロールバックの単体Test結果。
- 編集フォームと複数選択のWidget Test結果。
- 保存後の反映と元ファイル非変更のIntegration Test結果。

## 判定

個別・一括編集、安全性、失敗時処理のすべてを確認できた場合のみPASSとする。
