# 楽曲再生・一時停止 仕様書

## 文書情報

- 仕様ID: 2607312004
- 対応する全体要件: FR-009
- ステータス: Completed
- 作成日: 2026-07-31

## 1. 目的

ライブラリまたは検索結果から選択したローカル楽曲を再生し、一時停止できるようにする。

## 2. 対象範囲

### 対象

- 楽曲選択と再生開始
- 再生中楽曲の表示
- 再生・一時停止状態の表示と操作
- ファイル不存在・再生失敗時のエラー表示

### 対象外

- 次曲・前曲、キュー、シャッフル、リピート
- 音量、再生位置シーク、メディアキー
- ストリーミング再生

## 3. 要件

### 機能要件

- [x] REQ-001: 一覧または検索結果から楽曲を選択して再生できる。
- [x] REQ-002: 再生中の楽曲情報をプレイヤー領域に表示する。
- [x] REQ-003: 再生中の楽曲を一時停止できる。
- [x] REQ-004: 再生状態に応じて操作ボタンを更新する。
- [x] REQ-005: ファイルが存在しない、または再生できない場合に原因が分かるエラーを表示する。
- [x] REQ-006: 再生処理で音楽ファイルを変更しない。

### 非機能要件

- [x] NFR-001: `AudioPlayerService`を外部再生ライブラリから分離する。
- [x] NFR-002: 再生状態をPlayerViewModelで管理し、Fakeでテストできる。
- [ ] NFR-003: macOS / Windowsの両方で採用ライブラリの最小動作を検証する。

## 4. 完了条件

- [x] 選択、再生、一時停止、エラー表示が動作する。
- [x] 再生状態の単体・Widgetテストが成功する。
- [x] macOS Integration TestをFakeで実行し結果を記録する。Windowsは環境上未実行。
- [x] `flutter analyze` と `flutter test` が成功する。

## 5. 設計メモ

`AudioPlayerService`は`media_kit`への依存を隠蔽する。存在確認と再生エラーを分類し、ユーザー固有の絶対パスを不要に画面やログへ出さない。
