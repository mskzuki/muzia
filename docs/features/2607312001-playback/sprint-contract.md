# スプリント契約

## 対象範囲

機能: 楽曲再生・一時停止

対象要件: FR-009

## 観測可能な振る舞い

- 楽曲一覧または検索結果から選択した楽曲が再生される。
- 再生中の楽曲情報がプレイヤー領域に表示される。
- 再生中の楽曲を一時停止できる。
- ファイル不存在または再生失敗時にエラーが表示される。
- 再生操作で元の音楽ファイルが変更されない。

## 証拠

- Fakeプレイヤーによる状態遷移の単体Test結果。
- プレイヤーのWidget Test結果。
- macOS / Windowsでのテスト音源による再生・一時停止Integration Test結果。

## 判定

再生、一時停止、失敗時の表示を実音源または検証可能なFakeで確認できた場合のみPASSとする。
