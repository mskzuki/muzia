# レビュー指摘バグ修正 仕様書

## 文書情報

- 仕様ID: 2607312240
- 対応する全体要件: FR-002、FR-003、FR-009、FR-010、FR-011、FR-012、FR-014
- ステータス: Completed
- 作成日: 2026-07-31

## 1. 目的

レビューで確認された、macOS実機のファイルアクセス、一括編集によるメタデータ破壊、元ファイル由来メタデータの未保存を修正する。

## 2. 要件

- macOSサンドボックスアプリが、ユーザーが選択したフォルダを読み取れる。
- 一括編集で指定しない項目は、既存値を変更しない。
- 一括編集ダイアログは選択曲間で共通する現在値を事前入力する。
- ファイル解析結果を`track_source_metadata`へ保存し、表示用の`track_metadata`と分離する。
- メタデータ編集は`track_source_metadata`を変更しない。
- 既存DBはマイグレーション後も読み込み可能である。

## 3. 完了条件

- Debug/ReleaseのmacOS entitlementsにユーザー選択フォルダのread-only権限がある。
- 一括編集でタイトルが保持され、空欄の項目も既存値を消去しない。
- `track_source_metadata`の作成、初回保存、編集時非変更をテストで検証する。
- `flutter analyze` と `flutter test` が成功する。
