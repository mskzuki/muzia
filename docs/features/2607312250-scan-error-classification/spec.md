# スキャンエラー分類 仕様書

## 文書情報

- 仕様ID: 2607312250
- 対応する全体要件: FR-003、FR-005
- ステータス: Completed
- 作成日: 2026-07-31

## 1. 目的

音楽フォルダのスキャンで、空フォルダ、フォルダアクセスエラー、個別ファイルのメタデータ解析エラーを区別して表示する。

## 2. 要件

- 対象ファイルが0件で問題がない場合は空状態とする。
- フォルダ列挙に失敗した場合はアクセスエラーとする。
- 個別ファイルの解析失敗は記録し、他のファイルのスキャンを継続する。
- 全対象ファイルの解析に失敗した場合は解析エラーとする。
- 一部のファイルだけ解析に失敗した場合は、成功した楽曲を表示しながら警告する。

## 3. 完了条件

- 型付きスキャンイベントとアクセス例外を導入する。
- 上記4状態をViewModelテストで検証する。
- `flutter analyze` と `flutter test` が成功する。

## 4. 実装メモ

`FileScannerService`は`TrackFound`、`ScanIssueEvent`、`ScanCompleted`を返し、フォルダ列挙の`FileSystemException`は`FolderAccessException`として伝播する。ViewModelは解析失敗が全件の場合をエラー、一部の場合を警告付き成功として扱う。
