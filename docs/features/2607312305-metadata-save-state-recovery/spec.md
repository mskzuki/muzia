# メタデータ保存失敗後の一覧状態復帰

## 目的

メタデータ保存が一度失敗しても、再度の保存成功後に楽曲一覧を表示できる状態へ復帰させる。

## 対象範囲

- `LibraryViewModel.updateTracksMetadata` の成功時状態遷移
- 保存失敗後に再保存が成功するケースの単体テスト

## 要件

- メタデータ保存成功時は、現在の楽曲一覧に応じて `empty`、`ready`、または `readyWithWarnings` を設定する。
- メタデータ保存成功時は、保存失敗時のエラーメッセージを消去する。
- 保存失敗時の既存のエラー表示は維持する。
- 元の音楽ファイルや無関係な状態は変更しない。

## 完了条件

- 保存失敗後の再保存成功で `LibraryStatus.error` が一覧表示可能な状態へ戻る。
- 回帰テストが追加され、`flutter analyze` と `flutter test` が成功する。
