# 動画ファイル除外 仕様書

## 文書情報

- 課題ID: 2607312246
- 種別: 不具合
- 対応する全体要件: FR-003、FR-004
- ステータス: Completed
- 作成日: 2026-07-31

## 1. 目的

音楽フォルダのスキャンで、メタデータ解析ライブラリが対応している動画コンテナを音楽ファイルとして取り込まない。

## 2. 要件

- スキャン対象はアプリが定義した音声拡張子だけに限定する。
- `.mov` と `.mp4` はスキャン対象外とする。
- 大文字・小文字にかかわらず拡張子を判定する。
- 対応外ファイルはメタデータ解析Serviceへ渡さない。

## 3. 完了条件

- `.mov` / `.mp4` を含む非音声ファイルの除外テストがある。
- `flutter analyze` と `flutter test` が成功する。
