# 一括編集ダイアログの構造をハンドオフ§14に適合させる

## 文書情報

- 種別: 既存実装の是正（UIデザイン適合・仕様乖離）
- 作成日: 2026-09-02
- 参照: [docs/design_handoff/README.md](../../design_handoff/README.md) §14
  （「This is the source of truth for bulk tag editing.」）、
  `screenshots/17-multi-select.png` / `18-bulk-dialog.png` / `19-bulk-confirm.png`、
  `reference_html/screens2.jsx`
- 前提課題: [2609021644-track-metadata-model-extension](../2609021644-track-metadata-model-extension/spec.md)
  （ジャンル・リリース年。未完了の間は該当フィールドを除いた構造適合を先行できる）

## 事象

現在の一括編集ダイアログ
（[lib/features/library/presentation/metadata_edit_dialog.dart](../../../lib/features/library/presentation/metadata_edit_dialog.dart)
`BulkMetadataEditDialog`）は、ハンドオフ§14が明記する構造と食い違っている。

| 項目 | ハンドオフ§14 | 現在の実装 |
|---|---|---|
| 対象項目の選択 | 4項目（アーティスト/アルバム名/リリース年/ジャンル）を**常時表示、項目ごとのチェックボックスなし** | 項目ごとにチェックボックスで変更対象を選ぶ |
| アルバム名の下 | チェックボックス「選択していない同じアルバムの曲も含めて変更する」（未チェック=選択曲を新アルバムへ**分割**、チェック=アルバム全体を**リネーム**） | なし |
| リリース年 | 4桁 `YYYY` の狭い入力 | 自由記述「リリース情報」 |
| ジャンル | 単一値のテキスト入力+既存ジャンルのチップ | なし |
| 既存アルバム名への変更 | エラーでブロック（「「X」という名前のアルバムが既に存在します。」暗黙のマージ禁止） | 制限なし |
| 確認ダイアログ | 分割/リネームの結果を文章で説明（例「選択した3曲だけを『…』へ分割します。残り8曲は…」）+「ファイルには書き込まれません…」 | 変更する項目と値の列挙 |
| ヘッダ | タイトル+✕、インジゴチップ「N 曲を選択中」+対象アルバム名 | テキストのみ |

除外注記「曲名とトラック番号は、重複を避けるため一括編集できません。」と
選択バー（「N 曲を選択中」+一括編集ボタン、全選択リンクなし）は適合済み。

## 原因

一括編集は是正課題 2608222333 で「レイアウト構造が既にデザインに近いためトークン適用
のみ」と判断されたが、実際にはチェックボックス方式（REQ-004由来の
「対象項目の選択」解釈）とハンドオフの「常時表示・分割/リネーム切替」方式は
構造的に別物だった。

## 実装に先立つ確認事項

1. **FR-012との整合**: FR-012は「一括変更の対象項目と変更内容を確認できる」ことを
   求める。チェックボックス廃止後は「空欄のままの項目は変更しない」規則とし、
   確認ダイアログで適用内容を提示することで満たす。空欄にしたい（値を消す）操作が
   一括編集でできなくなる点は仕様として許容するか確認する。
2. **分割/リネームの適用範囲**: 「同じアルバムの曲も含めて変更する」をチェックした
   場合、選択外の曲にも変更が及ぶ。確認ダイアログで対象曲数を明示する。
3. **複数アルバムにまたがる選択**: ハンドオフはひとつのアルバム内の選択を想定
   （scope行に対象アルバム名を表示）。複数アルバムにまたがる場合の
   「含めて変更する」チェックボックスの挙動（非表示にする等）は実装時に方針を決め、
   作業報告に記載する。

## 要件

1. 項目ごとのチェックボックスを廃止し、アーティスト / アルバム名 / リリース年 /
   ジャンルの4フィールドを常時表示する。空欄のままの項目は変更しない。
   - 選択曲で値が一致する項目は現在値をプレースホルダまたは初期値として表示する。
2. アルバム名フィールドの下にチェックボックス
   「選択していない同じアルバムの曲も含めて変更する」を置く。
   - 未チェック: 選択曲のみ新アルバム名へ変更（分割）。
   - チェック: 同じアルバムの全曲を変更（リネーム）。
   - 選択がアルバム全曲と一致する場合は分割/リネームの区別が不要（単純リネーム）。
3. アルバム名の変更先がライブラリ内の既存アルバム名と一致する場合、保存をブロックし
   「「X」という名前のアルバムが既に存在します。」を表示する。
4. リリース年は4桁数値入力とする（数値以外・4桁以外は保存不可）。
5. ジャンルは単一値のテキスト入力+既存ジャンルのサジェストチップとする
   （前提課題の完了まではフィールドを追加しない）。
6. 確認ダイアログ「次の変更を適用します」で、分割/リネームを含む変更内容を
   文章の箇条書きで提示し、「ファイルには書き込まれません（編集はライブラリ内にのみ
   保存されます）。」を明記する。アクションは「戻る / 適用」。
7. ヘッダにインジゴチップ「N 曲を選択中」と対象（アルバム名等）を表示し、
   閉じる✕を置く。
8. 見た目（〜440px幅、角丸、ボタン様式）は `18-bulk-dialog.png` に合わせる。
