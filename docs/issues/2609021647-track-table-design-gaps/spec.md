# 楽曲一覧テーブルの残デザイン差分（時間列・イコライザ・ソート・⌘I）

## 文書情報

- 種別: 既存実装の是正（UIデザイン適合）
- 作成日: 2026-09-02
- 参照: [docs/design_handoff/README.md](../../design_handoff/README.md) §1、
  `screenshots/01-songs.png` / `15-context-menu.png`、
  [docs/issues/2608222333-design-handoff-alignment](../2608222333-design-handoff-alignment/spec.md)
- 前提課題: [2609021644-track-metadata-model-extension](../2609021644-track-metadata-model-extension/spec.md)
  （時間列に必要な `durationMs`）

## 事象

是正課題 2608222333 でテーブル化・選択・ゼブラ・選択バー・コンテキストメニューは
適合済みだが、以下がデザインと異なるまま残っている
（[lib/features/app_shell/presentation/app_shell_page.dart](../../../lib/features/app_shell/presentation/app_shell_page.dart)）。

- **時間列**: デザインは56px右寄せ・tabular figures。再生時間データがなく保留中。
- **再生中行のイコライザ**: デザインは#セルが3本バーのアニメーションに切り替わる。
  現在はタイトルのaccentText化のみ（是正課題で「任意」とされ未実装）。
- **列ソート**: デザインはタイトル等でソート可能。現在はソート手段なし。
- **⌘I ショートカット**: コンテキストメニューの「曲を編集…」にデザインは
  ⌘I表記があり、キーボードショートカットとしても機能する想定。現在は表記・
  バインドともなし。

デザインの**22pxカバーサムネイル・♥列・Quality列**はアートワーク/お気に入り/
品質情報がMVP後（requirements.md §7）のため本課題の対象外とする。

## 原因

是正課題 2608222333 の時点でデータ不足（時間）・優先度判断（イコライザ・ソート・
ショートカット）により見送られた項目の積み残し。

## 実装に先立つ確認事項

1. **ソートの範囲**: デザインで明示されるのはTitleソートとAlbums画面のSortボタン。
   本課題では楽曲一覧のヘッダクリックによる昇順/降順ソート
   （タイトル/アーティスト/アルバム/時間）を対象とし、ソート状態の永続化は
   行わない方針で良いか確認する。
2. **イコライザとReduce Motion**: OSの視差効果軽減設定時はアニメーションを
   停止する（ハンドオフのMotion指針）。

## 要件

1. 「時間」列（56px・右寄せ・tabular figures）を追加する。`durationMs` がnullの
   楽曲は「—」を表示する。
2. 再生中行の#セルを3本バーのイコライザ表示に切り替える。一時停止中は
   アニメーションを停止した状態で表示する。Reduce Motion時は静止させる。
3. ヘッダクリックで列ソート（昇順⇄降順）できるようにし、ソート中の列に
   方向インジケータを表示する。ソートロジックは単体テスト可能な形で分離する。
4. コンテキストメニューの「曲を編集…」に「⌘I」を表記し、行選択中の
   ⌘I（Windowsでは Ctrl+I）で編集ダイアログを開く。

## 完了条件

- `01-songs.png` と実機表示を並べ、時間列・再生中行の表現が一致する
  （サムネ・♥・Quality列の不在はMVP範囲判断として許容）。
- ソート・時間フォーマットの単体テスト、イコライザ表示・⌘IのWidgetテストがある。
- `flutter analyze` / `flutter test` が通る。
- 確認事項1〜2の判断が作業報告に記載されている。
