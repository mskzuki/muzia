# アーティスト詳細の残デザイン差分（05-artist-detail）

## 文書情報

- 種別: 既存実装の是正（UIデザイン適合）
- 作成日: 2026-09-02
- 参照: [docs/design_handoff/README.md](../../design_handoff/README.md) §5、
  `screenshots/05-artist-detail.png`
- 前提課題: [2609021644-track-metadata-model-extension](../2609021644-track-metadata-model-extension/spec.md)
  （楽曲行の時間表示）、
  [2609021649-player-transport-enablement](../2609021649-player-transport-enablement/spec.md)
  （再生アクションの連続再生）

## 事象

アーティスト/アルバムブラウザ
（[lib/features/library/presentation/artist_album_browser.dart](../../../lib/features/library/presentation/artist_album_browser.dart)）
は行スタイル・ヒーロー・アルバムカードが適合済みだが、デザイン `05-artist-detail`
と以下が異なる。

- **ヒーローのアクション**: デザインは「再生 / シャッフル / ♥」ボタン。現在はなし。
  シャッフル・♥はMVP後（requirements.md §7）のため対象外とし、**再生**
  （そのアーティストの楽曲を先頭から再生）のみ対象とする。
- **楽曲行**: デザインはインデックス+28pxカバー+タイトル+アルバム+時間。現在は
  番号+タイトル+アルバム名のみで、時間がなく、行から再生もできない
  （一覧テーブルと異なりダブルクリック再生・コンテキストメニューがない）。
- **楽曲セクションの表示条件**: デザインはアーティスト選択時点でTop Songsを表示。
  現在はアルバムを選択するまで楽曲セクションが表示されない。

カバーサムネイル（アートワーク）はMVP後のためプレースホルダで代替する。

## 原因

ブラウザ画面は一覧テーブルより先に簡易実装され、是正課題 2608222333 では
スタイル適合のみ行われたため、操作性（再生導線）と情報量の差が残った。

## 実装に先立つ確認事項

1. **ヒーローの再生ボタン**: 連続再生（キュー）が前提。課題 2609021649 の完了前は
   「先頭の1曲を再生」に留めるか、本課題を後続にするかを確認する。
2. **Top Songsの並び順**: デザインの「Top Songs」は再生回数等を示唆するが、
   再生履歴はMVP後。本課題ではアルバム未選択時に「全楽曲（アルバム順・
   トラック順）」を表示する読み替えで良いか確認する。

## 要件

1. ヒーローに「再生」ボタンを追加し、表示中のアーティストの楽曲を再生する。
2. アーティスト選択時点で楽曲セクションを表示する（アルバム選択でその
   アルバムの楽曲に絞り込む挙動は維持する）。
3. 楽曲行にプレースホルダカバー（28px）と時間（`durationMs`、null時「—」）を
   追加し、ダブルクリックで再生できるようにする。行の右クリックメニュー
   （曲を再生/曲を編集…/ライブラリから削除…）は楽曲一覧と共通化する。
4. 行の高さ・余白・タイポグラフィを `05-artist-detail.png` に合わせる。

## 完了条件

- `05-artist-detail.png` と実機表示を並べ、ヒーロー・アルバムカード・楽曲行の構成が
  一致する（シャッフル/♥/実カバーの不在はMVP範囲判断として許容）。
- 楽曲行の再生・編集・削除導線がWidgetテストで検証されている。
- `flutter analyze` / `flutter test` が通る。
- 確認事項1〜2の判断が作業報告に記載されている。
