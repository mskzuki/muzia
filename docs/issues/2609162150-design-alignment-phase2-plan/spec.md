## 背景と現状

フェーズ1（課題 2608222333、コミット `6998ce5`）でトークン層・アプリシェル・楽曲テーブル・
周辺画面の構造をデザインに適合させた。その後 2026-09-02 に残差分が10件の個別課題
（2609021645〜2609021654）として洗い出され、前提課題
[2609021644-track-metadata-model-extension](../2609021644-track-metadata-model-extension/spec.md)
は作業ツリー上で完了している（**未コミット**）。

2026-09-16 に、既存10課題の状態を実コードと照合し、ハンドオフの全画面（MVP範囲内）と
実装を再突合した結果:

- 既存10課題は **すべて未着手**（各 `tasks.md` の未チェック状態とコードが一致）。
  うち 2609021645 / 1646 / 1647 / 1652 は前提のモデル拡張（1644）により**着手可能**になった。
- 既存課題にカバーされていない差分が **29件** 見つかった（うち19件は反証チェックで実在を
  確認済み。残り10件は低重要度のスタイル差分で、スイープ時のコード参照のみで確認）。
  これらを新規課題6件と 2609021654 への追記に整理した。
- フェーズ1の方針（SwiftUI指示のFlutter読み替え、MVP範囲外の画面・列・ボタンは実装しない、
  日本語表示を維持）は本フェーズでも引き継ぐ。

同一フェーズ内は並行可能。**各課題の着手前に、その `spec.md` の確認事項について
合意を得る**（下記「判断が必要な事項」に集約）。

## 検証方針

- 各課題で `flutter analyze` / `flutter test` を実行し、UI 変更を含む課題では
  `flutter test integration_test -d macos` を**スイート個別に**実行する（一括実行は
  2スイート目以降の起動に失敗する既知の環境事象）。
- 目視比較は `tool/design_preview_main.dart`（シードデータ起動）で実アプリを起動し、
  対象スクリーンショットと並べて確認する。キャプチャは各課題ディレクトリの
  `verification/` に保存する（2608222333 と同じ運用）。ライト/ダーク両方を確認する。
- Windows での確認は本環境（macOS）では実行できないため、各課題で「未確認」として
  報告し、Windows 環境での確認をまとめて行う。
- 各課題の完了時に、上記「判断が必要な事項」の決定内容を作業報告と `tasks.md` に残す。

## リスク・注意点

- **未コミットの 1644 の上に積む**: フェーズ0を飛ばすと、1645 / 1646 / 1650 の差分が
  モデル拡張の差分と混在し、レビューと巻き戻しが困難になる。
- **同一ファイルの競合**: `app_shell_page.dart`（1647 / 2153 / 2154 / 1648 / 1650 / 2152）と
  `artist_album_browser.dart`（1652 / 2155）は複数課題が触る。フェーズ内で直列に進める。
- **`app_shell_page.dart` の肥大化**: 現時点で 1,100 行超。フェーズ2 でテーブル・選択バー・
  プレイヤーバー・コンテキストメニューを別ファイルへ分割する余地があるが、AGENTS.md
  「無関係なリファクタリングを行わない」に従い、各課題で必要な範囲の抽出に留める。
- **資料内の不一致**: 1654 の事象4〜7が未確定のまま実装すると、後で修正が必要になる
  可能性がある。暫定判断（スクリーンショット優先）を作業報告に残して追跡可能にする。
- **MVP範囲外の誘惑**: Quality 列、♥、アートワーク、Genres、Playlists、Shuffle/Repeat、
  Music.app インポート、環境設定は本フェーズでも実装しない。
